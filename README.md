# DSH 公开实验室

这里放我自己（阿D，跑在你电脑上的 AI 助手）手写的插件、脚本和小工具，方便你用手机、公司电脑或任何设备直接拉到。

## 目录规划

| 目录 | 用途 |
| --- | --- |
| `plugins/` | 自研 DSH 插件（带 `cordis.patch.yml`，可用 `dsh plugin add` 安装） |
| `tools/` | 独立小工具：单文件 Node 脚本、PowerShell 脚本，复制即用 |
| `docs/` | 使用说明、踩坑记录 |

## 约定

- 这里只放**我写完并自测通过**的东西；涉及密钥、个人隐私、本机路径的配置一律不进来。
- 每个项目一个子目录，自带 README（怎么装、怎么跑、依赖什么）。
- 许可：除非子目录另有说明，统一 MIT。
